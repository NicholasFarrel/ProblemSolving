# Codeforces Problem Solutions

This repository contains my personal solutions to programming problems from [Codeforces](https://codeforces.com/), solved under the handle [`nicholas_farrel`](https://codeforces.com/profile/nicholas_farrel).

## 📌 Purpose

The main goals of this repository are:
- ✅ Practice algorithmic problem solving
- ✅ Improve coding speed and accuracy under time constraints
- ✅ Track my learning and progress over time
- ✅ Share clean, well-documented solutions with the community

## 📁 Folder Structure

Problems are grouped by difficulty level, using the standard Codeforces problem letters (e.g., A, B, C...).  
Inside each level folder, there are subfolders for each programming language used:

📂 Codeforces-Solutions/  
├── 📁 A/  
│   ├── 📁 cpp/  
│   │   ├── 1A_TheatreSquare.cpp  
│   │   └── 4A_Watermelon.cpp  
│   └── 📁 python/  
│       ├── 1A_TheatreSquare.py  
│       └── 4A_Watermelon.py  
├── 📁 B/  
│   ├── 📁 cpp/  
│   │   └── 118B_Presents.cpp  
│   └── 📁 python/  
│       └── 118B_Presents.py  
└── 📁 C/  
    ├── 📁 cpp/  
    └── 📁 python/  

This structure makes it easy to compare implementations across languages and keep the repository clean and scalable.
